# Admin Panel — Boda Jean & Ana 💍

Panel de Administración independiente para la gestión en tiempo real de invitados y confirmaciones RSVP de la boda de **Jean & Ana (2026)**.

## 🚀 Características
- **Autenticación Segura:** Conectado directamente a Supabase Auth (Inicio de Sesión y Registro).
- **Métricas en Vivo:** Indicadores de asistencia (Total de Invitados, Confirmados, Declinados y Pendientes).
- **Filtros Dinámicos:** Búsqueda rápida por nombre, código de invitado, grupo/familia o estado de confirmación.
- **Detalles de Acompañantes:** Identificación clara de invitados titulares y acompañantes vinculados.

## 🛠️ Tecnologías
- HTML5 / CSS3 / JavaScript (Vanilla)
- [Supabase JS SDK v2](https://supabase.com/docs/reference/javascript/introduction)
